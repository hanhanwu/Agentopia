# UI Element Design

This directory contains approval-stage visual concepts for Agentopia and Skynet.

## Workflow

- Use SVG files as both editable design masters and review artifacts.
- Do not move a concept into the application until it is approved.
- Keep visual states tied to activity events; decoration must not imply unobserved activity.
- Preserve labels, symbols, and shape differences so color is never the only identifier.
- Reserve bright-white agent linework and glow for the user's own agent. Mochi keeps a dark body with white outlines and a subtle pink facial blush; every service, external, or system agent must use a distinct non-white identity color. Neutral white interface text and small facial details are not agent identity styling.
